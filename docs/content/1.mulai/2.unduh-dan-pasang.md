## Unduh

:download-button

Tombol di atas selalu mengarah ke versi terbaru di [GitHub Releases](https://github.com/narr07/sibos/releases/latest). Pilih berkas **`SIBOS_x.y.z_x64-setup.exe`**.

## Pasang

::steps{level="3"}
### Jalankan installer

Klik dua kali `SIBOS_x.y.z_x64-setup.exe`. Bila Windows SmartScreen muncul, pilih **More info → Run anyway**.

### Ikuti langkah installer

Lajur terpasang di `Program Files`. Bila WebView2 belum ada di komputer, installer memasangnya otomatis.

### Buka Lajur

Buka Lajur dari menu Start. Saat pertama kali dibuka, Lajur meminta Anda [menghubungkan ARKAS](/mulai/menghubungkan-arkas).
::

## Pembaruan

Lajur memeriksa versi baru secara otomatis. Bila ada, muncul notifikasi untuk mengunduh dan memasangnya, lalu aplikasi dibuka ulang. Pemeriksaan manual ada di menu **Pengaturan → Tentang Aplikasi**.

::tip
Data Lajur tidak hilang saat memperbarui aplikasi. Untuk berjaga-jaga, aktifkan [backup otomatis](/lainnya/backup).
::
