SIBOS membaca data dari database ARKAS (`arkas.db`). Database ini terenkripsi, jadi SIBOS butuh kunci database saat pertama kali menghubungkan.

::steps{level="3"}
### Pilih file database

SIBOS mendeteksi lokasi bawaan ARKAS secara otomatis, biasanya:

```txt
C:\Users\<nama pengguna>\AppData\Roaming\Arkas\arkas.db
```

Anda juga bisa memilih file lain, misalnya database simulasi atau salinan backup ARKAS.

### Isi kunci database

Masukkan kunci database ARKAS. Centang **Simpan kunci di Windows Credential Manager** supaya tidak perlu mengisi lagi saat aplikasi dibuka berikutnya.

### Pilih tahun anggaran dan sumber dana

Setelah terhubung, pilih tahun anggaran dan sumber dana di bagian atas halaman. Pilihan ini berlaku di semua menu dan diingat SIBOS.
::

::note
SIBOS hanya membaca database ARKAS. Bila ARKAS sedang dipakai mengisi transaksi, klik **Muat ulang** di halaman Koneksi ARKAS untuk melihat data terbaru.
::

## Status koneksi

Indikator di header menunjukkan status:

| Status | Artinya |
| --- | --- |
| Terhubung ke ARKAS | Database terbaca dengan baik |
| Database tidak ditemukan | Lokasi `arkas.db` salah atau ARKAS belum terpasang |
| Kunci belum diisi | Isi kunci database ARKAS |
| Kunci salah | Kunci database tidak cocok, isi ulang |
| ARKAS sedang sibuk | ARKAS sedang menulis ke database, coba lagi sebentar |

## Data sekolah dan pejabat

Nama sekolah, NPSN, alamat, kepala sekolah, bendahara, dan ketua komite diambil dari ARKAS. Semuanya bisa diubah di [Pengaturan](/lainnya/pengaturan) tanpa mengubah data ARKAS.
