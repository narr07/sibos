Data SIBOS (pengaturan, gabungan bukti, pajak manual, foto nota, isian generator) disimpan terpisah dari ARKAS. Cadangkan secara berkala.

## Backup

- **Backup data SIBOS** ke satu file, berisi database SIBOS dan foto nota.
- **Backup otomatis** setiap kali aplikasi dibuka, ke folder pilihan Anda, dengan jumlah file yang disimpan bisa diatur.
- **Salin arkas.db** ke folder pilihan sebagai salinan mentah database ARKAS.
- **Export semua laporan** satu tahun menjadi satu file Excel multi-sheet.

## Restore

Pilih file backup, periksa isinya (sekolah, tanggal, jumlah foto nota), lalu konfirmasi. SIBOS membuat backup otomatis sebelum menimpa data yang ada.

::warning
Restore menimpa seluruh data SIBOS di komputer ini. Data ARKAS tidak terpengaruh.
::
